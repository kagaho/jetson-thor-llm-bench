# Contributing

Contributions and reproducible benchmark reports are welcome.

1. Make a branch and add tests for behavior changes.
2. Run `make test` (offline; no GPU or model download).
3. Explain model variant, quantization, memory utilization, context, reasoning setting, power mode, and number of repetitions for performance changes.
4. Never include hostnames, personal paths, API tokens, model weights, private prompts, or raw user content in issues and pull requests.
5. Report timing methodology; do not compare unrelated prompts as though they were identical.

This repo is independent of NVIDIA, Qwen, and vLLM.
